了解单片机
1.什么是单片机
单片机是一个微控制器（MCU），一类将 CPU、存储器以及定时器、GPIO、通信接口等外设集成在单颗芯片上的嵌入式控制器
常见的单片机有：80C51、MSP430、STM32
2.单片机做什么的
主要用于嵌入式系统中的数据采集、逻辑处理、通信管理和执行器控制
3.单片机外面能接什么
传感器、执行器、显示设备、存储设备
单片机需要通过外部设备接口进行通信，常见的接口类型有：
数字输入输出接口GPIO
数字通信接口SPI、I2C、UART
而协议只负责 模块↔MCU ，不同的协议之间不会直接互相理解，而是通过单片机读取、解析、发送进行联系

本项目的学习主线：
1.单片机是什么、摄像头是什么、舵机是什么
单片机是一个微控制单元（MCU），一种集成电路芯片
摄像头是一种视频输入设备，由镜头与感光传感器（CCD/CMOS）两部分组成
舵机是一种位置（角度）伺服的驱动器，由外壳、舵盘、直流电机、减速齿轮组、角度传感器、控制驱动电路和接口线缆等部件组成
2.运用到的算法是什么
目前我只用到了LAB颜色阈值分割和Blob几何特征筛选，对于多自由度机械臂来说可以用以下两算法：
差分位移法（增量模式）（根据坐标变化判断移动变化）
运动学解算（角度投影模式）（正运动学：角度推位置；逆运动学：位置推角度）
在以后开始一个项目选算法时，我可以根据这个逻辑筛选：
最终需要输出什么？需要哪些变量？传感器能测到什么？单片机性能怎么样？机械臂需要控制几个自由度？测量值和控制量之间的关系是什么？
3.视觉模块向外输出的是什么
图像传感器向OpenMV输出数字图像数据
视觉模块像单片机输出的是算法处理后的目标状态编码成UART数据
4.单片机接收到的是什么。
将接收到的UART数据编码恢复成字节
5.单片机如何解析的
按照约定的通信格式将接收到的字节解码为程序内部状态

将解析到的内部状态进行控制逻辑判断，生成对执行器的命令
再将目标命令映射为定时器CRR 值，由TIM3产生对应PWM值

调试流程：
1. 第一步：电源排查，优先确认整套设备供电状态。
2. 第二步：视觉排查，校验视觉单元输出。
3. 第三步：单片机排查，下发运动指令，检验舵机可否正常响应动作。
4. 第四步：舵机排查，检查运动边界，校验输出坐标值是否超出电机允许的运动区间。
5. 第五步：数据包校验：
单片机是否成功接收数据包
数据转换流程有无异常
是否出现数据包堆叠、报文冲突。
